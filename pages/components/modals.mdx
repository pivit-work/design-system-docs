# Modals

중요한 정보를 강조하거나 사용자의 결정을 받아야 할 때 사용하는 오버레이 컴포넌트입니다.
본문 컨텍스트 위에 패널이 올라와 주의를 집중시킵니다.

Figma 컴포넌트: `Modal`, `_Modal header`, `_Modal actions`

---

## Horizontal

아이콘과 텍스트가 가로로 배치되는 기본 타입입니다. Confirm/Cancel 같이 단순한 결정을 받을 때 가장 많이 씁니다.

### Brand (Success)

<ComponentPreview code={`<Modal
  type="horizontal"
  icon="brand"
  title="Blog post published"
  description="This blog post has been published. Team members will be able to edit this post and republish changes."
  secondaryLabel="Cancel"
  primaryLabel="Confirm"
/>`}>
  <Modal
    type="horizontal"
    icon="brand"
    title="Blog post published"
    description="This blog post has been published. Team members will be able to edit this post and republish changes."
    secondaryLabel="Cancel"
    primaryLabel="Confirm"
  />
</ComponentPreview>

### Warning

저장되지 않은 변경사항 등 경고를 표시할 때 사용합니다.

<ComponentPreview code={`<Modal
  type="horizontal"
  icon="warning"
  title="Unsaved changes"
  description="Do you want to save or discard changes?"
  secondaryLabel="Discard"
  primaryLabel="Save changes"
/>`}>
  <Modal
    type="horizontal"
    icon="warning"
    title="Unsaved changes"
    description="Do you want to save or discard changes?"
    secondaryLabel="Discard"
    primaryLabel="Save changes"
  />
</ComponentPreview>

### Destructive

되돌릴 수 없는 파괴적 액션(삭제 등)을 확인받을 때 사용합니다. Primary 버튼이 빨간색으로 표시됩니다.

<ComponentPreview code={`<Modal
  type="horizontal"
  icon="error"
  title="Delete blog post"
  description="Are you sure you want to delete this post? This action cannot be undone."
  secondaryLabel="Cancel"
  primaryLabel="Delete"
  primaryDestructive
/>`}>
  <Modal
    type="horizontal"
    icon="error"
    title="Delete blog post"
    description="Are you sure you want to delete this post? This action cannot be undone."
    secondaryLabel="Cancel"
    primaryLabel="Delete"
    primaryDestructive
  />
</ComponentPreview>

## Actions Layout

액션 영역은 3가지 레이아웃을 지원합니다.

### Right aligned (default)

<ComponentPreview code={`<Modal
  actionsLayout="right"
  ...
/>`}>
  <Modal
    type="horizontal"
    icon="brand"
    title="Blog post published"
    description="Team members will be able to edit this post and republish changes."
    secondaryLabel="Cancel"
    primaryLabel="Confirm"
    actionsLayout="right"
  />
</ComponentPreview>

### Fill container (horizontal)

버튼이 가로 너비를 균등하게 채웁니다.

<ComponentPreview code={`<Modal
  actionsLayout="fill"
  ...
/>`}>
  <Modal
    type="horizontal"
    icon="brand"
    title="Blog post published"
    description="Team members will be able to edit this post and republish changes."
    secondaryLabel="Cancel"
    primaryLabel="Confirm"
    actionsLayout="fill"
  />
</ComponentPreview>

### Stacked (vertical)

버튼을 세로로 쌓습니다. Primary 가 위, Secondary 가 아래입니다.

<ComponentPreview code={`<Modal
  actionsLayout="stacked"
  ...
/>`}>
  <Modal
    type="horizontal"
    icon="brand"
    title="Blog post published"
    description="Team members will be able to edit this post and republish changes."
    secondaryLabel="Cancel"
    primaryLabel="Confirm"
    actionsLayout="stacked"
  />
</ComponentPreview>

## With Helper

좌측에 체크박스, 링크 등 부가 컨트롤을 배치할 수 있습니다. `helper` prop으로 JSX 를 전달합니다.

<ComponentPreview code={`<Modal
  helper={<label><input type="checkbox" /> Don't show again</label>}
  ...
/>`}>
  <Modal
    type="horizontal"
    icon="brand"
    title="Blog post published"
    description="Team members will be able to edit this post and republish changes."
    secondaryLabel="Cancel"
    primaryLabel="Confirm"
    helper={
      <label style={{ display: 'inline-flex', alignItems: 'center', gap: 6, cursor: 'pointer' }}>
        <input type="checkbox" /> Don't show again
      </label>
    }
  />
</ComponentPreview>

## Body Content

아이콘/제목/설명 이외에 폼이나 리스트 등 본문 컨텐츠가 필요하면 `children` 으로 전달합니다.

<ComponentPreview code={`<Modal title="Team settings" description="Manage your team preferences.">
  <p>여기에 폼/리스트 등 본문을 넣습니다.</p>
</Modal>`}>
  <Modal
    type="stacked-left"
    icon="none"
    title="Team settings"
    description="Manage your team preferences."
    secondaryLabel="Cancel"
    primaryLabel="Save"
  >
    <div style={{ padding: '12px 0', color: 'var(--colors-text-textSecondary, #687079)' }}>
      여기에 폼/리스트 등 본문 콘텐츠를 넣습니다.
    </div>
  </Modal>
</ComponentPreview>
